# Content

Authored educational content (MDX): the analogies, explanations, and prose
for each concept's lesson stages.

This directory is intentionally empty. No concept content exists yet —
seeding it with placeholder text would misrepresent curriculum coverage.
Real content lands alongside the lesson engine (see `src/lessons`) and the
curriculum metadata it's attached to (see `src/curriculum/metadata`).

Convention (to be finalized when the first lesson ships): one MDX file per
concept, colocated under its track, e.g. `ml/linear-regression.mdx`.
