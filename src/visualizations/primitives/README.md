# Visualization primitives

Low-level, reusable building blocks for interactive visualizations —
scale helpers, responsive SVG/canvas wrappers, coordinate utilities — that
concrete visualizations (see `../components`) compose.

Empty for now: this project doesn't depend on D3 or React Flow yet, and
adding primitives ahead of a real consumer would be speculative. These
land with Phase 3 (the knowledge graph and the first playgrounds).
